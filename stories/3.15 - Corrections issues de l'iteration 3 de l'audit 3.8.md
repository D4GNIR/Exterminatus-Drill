## Objectif

Lever le **KO `I7 [B]`** et le **KO mineur `I4`** relevés par l'**itération 3** de l'audit `3.8` (2026-09-27, auditeur indépendant `po`). Le but est qu'une **itération 4** puisse rendre un verdict **Autorisé** et ouvrir le commit de la phase 3.

Le code de production n'est **pas** en cause : C3, B5, B6, B7, l'exécution headless et les 363 assertions sont conformes. Les écarts portent **uniquement** sur les documents de suivi (`stories/BACKLOG.md`, `stories/AVANCEMENT.md`, `stories/3.8 - …`).

Cette story impose donc une **recherche plein texte** de toutes les affirmations de compteur, pas une retouche des seules lignes listées.
